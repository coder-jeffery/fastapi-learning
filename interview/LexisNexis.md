    BM25和向量检索数值如何合并问题？
        解决思路：归一化，再融合 合并需要两种分数映射到同一值域（0-1） 合理融合策略到综合分数
        解决方案：
            1.向量检索分数预处理 （0-1的相似度） 
                余弦定理相似度 （本身0-1 完全不相似=0 完全相似=1）无须处理
                欧式定力/曼哈顿距离：数值越大越不相似，转换为相似度 ()
                    // vector_similarity = 1 / (1 + distance)  # 映射到 0-1
            2.归一化： BM25 分数归一化 映射0-1 （BM25 分值 0-∞ 或 0-100 或 0-任何数）三种归一化方式处理：
                min-max归一化
                截断归一化
                Z-Score+Sigmoid归一化
            3.融合策略：归一化之后两种分数0-1之间 策略合并： 0 < 阿尔法 < 1 
                a.加权线形融合    
                b.排序融合 
                c.层级融合
                d.学习型融合
    归一化本质：
        消除量岗差异，均值和标准差，多指标融合，分值归一化
        场景：除了 BM25 + 向量检索，还会引入TF-IDF 分值、关键词匹配数、文档与查询的重叠度、
        文档时效性分值等指标（如 TF-IDF 值域 0~∞，关键词匹配数 0~N，时效性分值 0~1），需要融合为综合检索分。
    多特征检索融合（大模型 RAG 进阶场景）
        场景：除了 BM25 + 向量检索，还会引入TF-IDF 分值、关键词匹配数、文档与查询的重叠度、文档时效性分值等指标（如 TF-IDF 值域 0~∞，关键词匹配数 0~N，时效性分值 0~1），需要融合为综合检索分。
        痛点：比如时效性分值（0~1）会被 TF-IDF（0~20）完全压制，直接加权无意义。
        适配方法：若指标有极值（如 TF-IDF）用截断 Min-Max/Z-Score+Sigmoid，无极值（如时效性）用基础 Min-Max，统一映射到 0-1 后再融合。
    线性回归、逻辑回归、SVM、KNN、梯度下降类模型（XGBoost/LightGBM）的特征工程。
        例：预测用户消费能力，特征包括「月收入（0~10 万）、消费次数（0~100）、年龄（0~100）、客单价（0~1 万）」。
